# Sapu Berita di iPhone

Baca berita Indonesia tanpa iklan, tanpa "Baca Juga", dan semua halaman langsung digabung. Gratis, tanpa App Store.

> **Untuk maintainer:** ganti `TAUTAN_ICLOUD` di bawah dengan tautan iCloud Shortcut (lihat `apps/ios-shortcut/README.md`).

## Pasang (sekali saja, ±1 menit)

1. Buka tautan ini di iPhone: **TAUTAN_ICLOUD**
2. Ketuk **Tambahkan Pintasan** (*Add Shortcut*).
3. Izinkan pintasan menjalankan skrip:
   **Pengaturan → Apps → Pintasan → Lanjutan → nyalakan "Izinkan Menjalankan Skrip"**
   (*Settings → Apps → Shortcuts → Advanced → Allow Running Scripts*)

## Pakai

1. Buka artikel berita di **Safari** (Detik, Kompas, Tribunnews, CNN Indonesia, Liputan6, dan lainnya).
2. Ketuk tombol **Bagikan** (kotak dengan panah ke atas).
3. Pilih **Sapu Berita**.
   - Pertama kali per situs, iPhone akan bertanya apakah pintasan boleh mengakses situs itu. Pilih **Izinkan Selalu**.
4. Artikel bersih langsung tampil. Tombol **Aa** untuk ukuran huruf, jenis huruf, tema gelap/sepia, dan bahasa. Tombol **Asli** untuk kembali ke halaman asli.

**Tips:** supaya lebih cepat, geser daftar aplikasi di lembar Bagikan ke paling kanan → **Edit Tindakan** → taruh **Sapu Berita** di Favorit.

## Kalau tidak muncul

- Pastikan artikelnya dibuka di **Safari**, bukan di browser bawaan WhatsApp/Instagram. Di WhatsApp: ketuk tautan → tombol Safari/kompas di pojok.
- Halaman depan situs (bukan artikel) memang tidak dibersihkan.
- Pengaturan (ukuran huruf, tema) disimpan per situs: atur sekali di tiap situs berita.

## Privasi

Semua berjalan di iPhone kamu. Sapu Berita tidak punya server, tidak mengirim apa pun ke mana pun, dan tidak tahu apa yang kamu baca.
