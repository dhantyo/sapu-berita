# Sapu Berita di Android

Baca berita Indonesia tanpa iklan, tanpa "Baca Juga", dan semua halaman langsung digabung. Setelah dipasang, tautan berita dari WhatsApp, Telegram, atau mana pun langsung terbuka bersih.

> **Versi alfa.** Untuk sementara aplikasi dibagikan langsung (APK), belum lewat Play Store.

## Pasang

1. Unduh **Sapu Berita.apk** dari tautan yang dibagikan.
2. Buka file-nya. Kalau ponsel bertanya, izinkan **"Instal aplikasi tidak dikenal"** untuk browser/file manager yang kamu pakai.
3. Buka **Sapu Berita**, lalu:
   1. Ketuk **Jadikan Sapu Berita browser utama** → pilih **Sapu Berita** → **Setel sebagai default**.
   2. Cek **Tautan lain dibuka di:** sudah browser yang biasa kamu pakai (Chrome, Brave, dll.). Ketuk untuk mengganti.
   3. Ketuk **Buka contoh artikel Kompas** untuk mencoba.

## Pakai

Tidak perlu apa-apa lagi. Ketuk tautan berita seperti biasa:
- **Berita** (Detik, Kompas, Tribunnews, CNN Indonesia, Liputan6, dan ±20 situs lain) → terbuka bersih di Sapu Berita.
- **Tautan lain** → langsung terbuka di browser biasamu, seperti sebelumnya.

Di artikel: tombol **Aa** untuk ukuran huruf, jenis huruf, tema gelap/sepia, dan bahasa (berlaku untuk semua situs). Tombol **Asli** untuk melihat halaman aslinya.

## Catatan

- Tautan yang dibuka di dalam aplikasi Instagram/Facebook memakai browser bawaan mereka sendiri, jadi tidak lewat Sapu Berita. Pilih **Buka di browser** dari menu ⋮.
- Mau berhenti? Pengaturan → Aplikasi → Aplikasi default → Aplikasi browser → pilih browser lain, atau hapus Sapu Berita.

## Privasi

Semua berjalan di ponselmu. Sapu Berita tidak punya server, tidak mengirim apa pun, dan tidak tahu apa yang kamu baca.
