# Sapu Berita di Android

Baca berita Indonesia tanpa iklan, tanpa "Baca Juga", dan semua halaman langsung digabung. Setelah diatur sekali, tautan berita dari WhatsApp, Telegram, atau mana pun langsung terbuka bersih. **Browser kamu tetap seperti biasa**; hanya tautan artikel berita yang dibuka Sapu Berita.

> **Versi alfa.** Untuk sementara aplikasi dibagikan langsung (APK), belum lewat Play Store.

## Pasang

1. Unduh **Sapu Berita.apk** dari tautan yang dibagikan.
2. Buka file-nya. Kalau ponsel bertanya, izinkan **"Instal aplikasi tidak dikenal"** untuk browser/file manager yang kamu pakai.
3. Buka **Sapu Berita**, lalu:
   1. Ketuk **Atur tautan berita** → **Tambahkan link** (*Add link*) → centang semua situs berita → **Tambahkan**.
   2. Kembali ke Sapu Berita: tulisannya berubah jadi **"Aktif untuk 16 dari 16 situs berita"**.
   3. Ketuk **Buka contoh artikel Kompas** untuk mencoba.

**Android 11 atau lebih lama:** tidak ada langkah 3.1. Saat pertama kali membuka tautan berita, ponsel bertanya aplikasi mana yang dipakai: pilih **Sapu Berita**, lalu **Selalu**.

## Pakai

Tidak perlu apa-apa lagi. Ketuk tautan berita seperti biasa:
- **Artikel** dari Detik, Kompas, Tribunnews (termasuk situs daerahnya), CNN Indonesia, CNBC Indonesia, Liputan6, Merdeka, Suara, Okezone, Viva, iNews, JPNN, ANTARA, Republika, Bisnis.com, Tirto → terbuka bersih di Sapu Berita.
- **Halaman depan / rubrik** situs-situs itu, dan **semua tautan lain** → terbuka di browser biasamu.

Di artikel: tombol **Aa** untuk ukuran huruf, jenis huruf, tema gelap/sepia, dan bahasa (berlaku untuk semua situs). Tombol **Asli** untuk melihat halaman aslinya.

## Catatan

- Kalau aplikasi resmi sebuah situs (misalnya aplikasi Detik) terpasang, tautan situs itu tetap dibuka aplikasi resminya; Android tidak mengizinkan aplikasi lain mengambil alih. Situs lainnya tetap lewat Sapu Berita.
- Tautan yang dibuka di dalam aplikasi Instagram/Facebook memakai browser bawaan mereka sendiri, jadi tidak lewat Sapu Berita. Pilih **Buka di browser** dari menu ⋮.
- Mau berhenti? Pengaturan → Aplikasi → Sapu Berita → **Buka secara default** → matikan, atau hapus aplikasinya.

## Privasi

Semua berjalan di ponselmu. Sapu Berita tidak punya server, tidak mengirim apa pun, dan tidak tahu apa yang kamu baca.
